# Kaizen — FullStack Portfolio

A conversion-focused portfolio built with **Next.js 15**, **Tailwind CSS**, and **GSAP** — targeting startup founders, SaaS companies, fintech teams, and AI tool builders.

## Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v3 + CSS custom properties
- **Animations**: GSAP + ScrollTrigger, Lenis smooth scroll
- **Charts**: Recharts (interactive demo widget)
- **Language**: TypeScript
- **Package manager**: pnpm

## Features

- ⚡ Preloader with GSAP animation
- 🎯 Conversion-focused hero with "Book a Call" CTA
- 📊 Interactive live dashboard demo (Recharts + AI prompt simulation)
- 💼 Case study project pages (Problem / Solution / Result)
- 🧠 "How I Think" differentiation section
- 💬 Testimonials section
- 🎨 Custom cursor + particle background
- 📜 Smooth scroll (Lenis)
- 📈 Google Analytics + click event tracking
- 🗺 Sitemap + robots.txt
- 📱 Fully responsive (mobile-first)
- ♿ Accessible (semantic HTML, ARIA labels)
- 🚀 Lighthouse ≥ 90 target

## Quick Start

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
